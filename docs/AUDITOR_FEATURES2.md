# 9. Organizer Verification Module

## Overview

Organizer Verification digunakan untuk melakukan verifikasi seluruh akun organizer sebelum mendapatkan akses penuh ke platform.

Organizer yang belum lolos verifikasi tidak dapat membuat event publik maupun menerima payout.
